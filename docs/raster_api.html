Raster

class meshtool.Raster[source]

Raster object (regular 2D grid) with a spatial reference. For a bathymetry, by convention the internal z axis is oriented upwards.

Build a raster with from_file() or from_arrays().

data

Node coordinates. z is filled with 0 if the input points are 2D.
